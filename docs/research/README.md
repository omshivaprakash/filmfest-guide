# Film festival research

A worldwide reference on film festivals, gathered in November 2026 to plan and fill FilmFest Guide. It is a **work in progress**, and some of it is wrong or out of date. Please help fix it.

- **[REPORT.md](REPORT.md)**: the full report. It covers FIAPF accreditation, festivals by region, Indian festivals (IFFI, IFFK, BIFFes and more), specialised festivals, 2025–2026 winners, markets and funds, statistics, a data model and open data sources.
- **[notes/](notes/)**: the raw research notes behind the report, one file per topic.

## How to read the tags

| Tag | Meaning |
|---|---|
| **[V]** | Checked on the cited page in Nov 2026 |
| **[S]** | Seen only in a search result or headline |
| **[BG]** or **†** | Background knowledge, **not checked**. Treat it as a lead |

Coordinates are approximate. No fees or deadlines were checked.

## Fix a mistake

1. Open the file on GitHub and press the pencil icon (**Edit this file**). GitHub makes a copy for you if needed.
2. Correct the line, change its tag to **[V]**, and add a link to the official source next to it.
3. Choose **Propose changes**, then **Create pull request**.

Not comfortable editing? [Open an issue](https://github.com/omshivaprakash/filmfest-guide/issues/new?title=Research%20correction:%20&labels=research) with the festival, year, what's wrong and a source link.

Facts here move into the app only after they are checked against a source. See [Contributing](../CONTRIBUTING.md).
